# Corrections, attribution and safe contact

**Canonical corrections policy:** https://grokarchivehub.com/corrections

**Contact and source-tip information:** https://grokarchivehub.com/contact

If you spot a broken link, incorrect headline, mistaken identity, date discrepancy, or source-attribution problem in this index, please reference the **public URL and specific field** in your correction.

- Don't upload personal data, confidential legal files, images identifying victims, restricted evidence or private financial/email attachments to a GitHub issue or pull request.
- Do not post unverified accusations about named individuals.
- Provide a public correction source or citation where available; GAH will compare the documentary record and update the canonical investigation if warranted.
- GitHub edits are not a substitute for corrections to a GAH article.

These URLs are not guaranteed confidential submission channels. Contact GAH before discussing whether any sensitive source requires a specialized secure process.
